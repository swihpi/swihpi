# GitHub Projects

- [PromptFoundry](https://github.com/swihpi/PromptFoundry) — A native macOS workspace for turning rough ideas into comprehensive prompts and handing them to Codex.
- [oci-cli-operations-mcp-codex](https://github.com/swihpi/oci-cli-operations-mcp-codex) — A local-first OCI CLI MCP and official Oracle documentation workflow for Codex.
- [silent-listener](https://github.com/swihpi/silent-listener) — A Windows text-only Gemini question-answering desktop prototype.
- [stereo-forge-au](https://github.com/swihpi/stereo-forge-au) — Open-source macOS AUv2 stereo imaging and chorus effect.
- [codex-usage-menubar](https://github.com/swihpi/codex-usage-menubar) — A native macOS menu bar utility for ChatGPT/Codex usage and reset times.
- [vela-gesture-demo](https://github.com/swihpi/vela-gesture-demo) — A native Swift macOS gesture controller for Zoom, built with Apple's Vision framework.
